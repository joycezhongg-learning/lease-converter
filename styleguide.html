Lease Convert design system

Every component on this page is rendered by the app's own app.css. Change a token there and this page and the app change together. Names match the Figma library (Lease Convert file, "Design system" page).

Colour

Semantic tokens only: name the job, not the hue. Each has a light and a dark value; switch the theme above.

Type

System font (SF Pro on iPhone). Six sizes, three weights.

Space

4px base with half steps for tight UI. A few one-off layout values (9, 18, 22px) stay literal.

Radius

Button

.btn + one variant. Chip for secondary actions in a card, outline for links out, primary for the one main action on a page, icon for swap, text for inline actions, unit for the menu inside an input.
